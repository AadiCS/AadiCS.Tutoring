# Student to Student Tutoring

A simple website for our free, student-run tutoring program for grades 2–10.

Live site: https://aadics.github.io/AadiCS.Tutoring/

## Files

- `index.html`: our story, program numbers, subjects, tutor roster, FAQs, and contact details.
- `signup.html`: student requests and volunteer applications, using our existing Google Forms.
- `styles.css`: shared layout and mobile styles.
- `script.js`: accessible mobile navigation. The pages and signup links also work without JavaScript.

## Preview locally

Open `index.html` in a browser, or run `python3 -m http.server 8000` from this folder and visit http://localhost:8000.

No build step or third-party packages are needed.

## Keeping information current

Update the dated program numbers in `index.html` as participation changes. The September 2026 figures are 15 student tutors and about 30 students helped. The displayed roster includes some of the tutors, not the entire volunteer network.

Keep the two Google Forms URLs and contact details consistent in both HTML files. Check grade levels, tutor availability, and the roster when the program changes. Only add student stories, photos, or testimonials with permission.
